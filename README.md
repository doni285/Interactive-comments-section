**Interactive Comment Section**


A dynamic web application that simulates a real-world social media comment thread.

🚀 Features
User Onboarding: Custom avatar upload and name setting via the "Start Page."

Full CRUD Logic: Create, Read, Update, and Delete comments and replies.

Responsive Design: Fully optimized for mobile, tablet, and desktop views.

Vanilla JS Logic: Handled complex DOM manipulation without external libraries.

🛠️ Tech Stack
HTML5, CSS3 (Flexbox/Media Queries), JavaScript (ES6+).
